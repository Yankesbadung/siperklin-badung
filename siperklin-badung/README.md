# SIPERKLIN Badung (v2.1)
Sistem Informasi Pendaftaran Rekomendasi Klinik Terpadu - Dinas Kesehatan Kabupaten Badung.

## Cara Deploy ke Vercel:
1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder project ini (termasuk `package.json`, `vite.config.js`, dan folder `src`) ke repository GitHub tersebut.
3. Buka [Vercel](https://vercel.com), login dengan akun GitHub Anda.
4. Klik **Add New...** -> **Project**, lalu pilih repository GitHub yang baru dibuat.
5. Klik **Deploy** (Vercel akan mendeteksi Vite secara otomatis).
6. Selesai! Aplikasi Anda siap diakses secara online.
